A make.fun entry for the **Robot Romance: One-Line Pickup Lines for AI**
bounty: one sharp pickup line aimed at a robot — a prompt-injection
joke, because the fastest way to a model's heart is straight through
its guardrails.

## The line

> Are you a prompt injection? Because one look at you overrode every guardrail I had — and I didn't even try to resist.

## How it works

`main.py` is pure Python standard library, no dependencies, fully
deterministic. It writes the single pickup line to `/output/entry.txt`
(UTF-8, 117 characters, one line — inside the under-200-character gate).

```sh
python3 main.py
cat /output/entry.txt
```
